# PureEssence Beauty Studio

PureEssence is a responsive, single-page beauty studio website for a home-based studio in Longford, Tasmania. The experience is designed around the **Quiet Glow Atelier** direction: warm editorial typography, cream and oat surfaces, champagne-clay accents, and a calm enquiry journey.

## Technology

The project uses React 19, TypeScript, Vite, Tailwind CSS 4, lucide-react icons, and the static Manus WebDev template. It is frontend-only by design; the enquiry form validates in the browser and is structured so an email or booking provider can be connected later without rebuilding the page.

## Run locally

```bash
pnpm install
pnpm dev
```

For a production build:

```bash
pnpm check
pnpm build
pnpm start
```

## Edit the business content

Business details, service categories, service descriptions, prices, durations, gallery items, image URLs, and contact placeholders are centralized in `client/src/data/siteContent.ts`. Replace placeholder values there rather than editing the page layout.

The main page and reusable display helpers are in `client/src/pages/Home.tsx`. Global styles, responsive breakpoints, typography, colors, and motion live in `client/src/index.css`.

## Replace placeholders

The current project intentionally does not invent private contact details, social accounts, prices, treatment claims, qualifications, reviews, or a residential address. Replace the following when available:

| Placeholder | File / area |
|---|---|
| Phone and email | `client/src/data/siteContent.ts`, `siteContent.contact` |
| Instagram and Facebook links | `client/src/pages/Home.tsx`, contact and footer social links |
| Service prices and durations | `client/src/data/siteContent.ts` |
| Owner portrait | `client/src/pages/Home.tsx`, `.owner-placeholder` slot |
| Gallery images | `client/src/data/siteContent.ts`, `galleryItems` |
| Enquiry delivery | `handleSubmit` in `client/src/pages/Home.tsx` |

The gallery accepts one image URL per item. Replace the temporary warm editorial image URLs with your own hosted images. Keep meaningful alt text for accessibility and local SEO.

## Enquiry form integration

The current form is an enquiry/request form. It validates name, phone, email, service, preferred date, preferred time, and message, then shows a confirmation state explaining that the request is not an automatic appointment confirmation. Connect the submit handler to a real email or booking service when those details are ready.

## Deployment

The project is ready for a static deployment. Within Manus, create a checkpoint and use the project’s Publish action. If deploying elsewhere, use the output generated by `pnpm build` and configure the host to serve `index.html` for the root route.
